Entrar como director

Con la contraseña ves los conflictos y los nombres, y puedes editar los eventos de tu ministerio.

Configurar edición

Esto se hace una sola vez. La página necesita un token de GitHub con permiso solo sobre este repo:
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → calendario-ministerios.
  3. Permissions → Repository → Contents: Read and write. Vence en 1 año.
Usa la misma contraseña que guardaste en el secreto EDIT_PASSWORD del repo; con ella se abre la lista de equipos.

¿Qué ministerio vas a editar?

Solo podrás crear, cambiar o borrar eventos de ese ministerio. Los demás los ves, pero bloqueados.
